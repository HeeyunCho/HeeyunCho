# Security Policy: Unified Agentic Framework (UAF)

## 🛡️ The Celestial Safety Gate
As of **April 2026**, the Unified Agentic Framework (UAF) and all 23+ associated repositories are protected by a mandatory, automated security gate.

### 🛡️ Automated Protections
1.  **Entropy-Based Scanning**: Every commit is scanned for high-entropy strings (secrets, API keys, tokens) using a high-performance Go-native engine.
2.  **Hygiene Auditing**: Automated detection of "documentation leaks" (unintended .html, .pdf, or .docx files in source directories).
3.  **Harness Engineering**: Transactional write-loops ensure that no unverified or non-compliant changes are ever committed to the core ecosystem.

## 🛡️ Reporting a Vulnerability
We take the security of this agentic ecosystem seriously. If you identify a potential security vulnerability, please follow these steps:

1.  **Do NOT** open a public issue.
2.  Email your findings directly to the maintainer at `heeyun.cho.de@gmail.com`.
3.  Include a detailed description of the vulnerability, reproduction steps, and potential impact.

## 🛡️ Response Process
*   **Acknowledgment**: Within 24 hours.
*   **Triage & Resolution**: Critical vulnerabilities are resolved within 48 hours via an automated 'Self-Healing' deployment loop.
*   **Disclosure**: A detailed security advisory will be published after the fix has been verified and deployed across the ecosystem.
