## Selected work

| Project | What it is |
|---|---|
| [CAN database diff and browser](https://heeyun.dev/projects/can-dbc-diff-explorer) | A Rust and Tauri desktop tool, with a matching CLI, that compares two versions of a CAN database (DBC) file and sorts the changes by whether they break an ECU's software. |
| [WPC Log Viewer](https://heeyun.dev/projects/bench-terminal-log-viewer) | A Windows desktop tool for wireless-charging bench work: a terminal (serial, SSH, Telnet, raw TCP) beside a filterable, indexed log, with CAN FD trace and UDS decoding lined up with the device log. |
| [Email assistant](https://heeyun.dev/projects/email-assistant) | A LangGraph agent that triages my Gmail, drafts replies for me to send and escalates what needs me. It has no way to send mail, and a test keeps it that way. |
| [Taking Note](https://heeyun.dev/projects/realtime-meeting-transcription) | A Windows 11 meeting recorder: a Rust WASAPI engine that keeps my microphone and remote participants on separate channels, feeding transcription into a Tauri app and Claude Code over MCP. |
| [everything-compare](https://heeyun.dev/projects/file-compare-tool) | One desktop app for text, folder, binary and document diffs, with a Rust engine and a React/Monaco UI. |
| [Governed context sharing](https://heeyun.dev/projects/governed-context-sharing) | A CLI that gives several AI tools the same approved view of a project; agents only propose changes, and a human approves each one. |

**Try them:** the [Lab](https://heeyun.dev/lab) has live, in-browser demos (CAN bus monitor, DBC diff, bench log replay, the email assistant's pipeline and more), all running on invented data.
