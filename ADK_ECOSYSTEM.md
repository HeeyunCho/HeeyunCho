# ADK ECOSYSTEM: Unified Agent Architecture

## 🌐 Overview
The ADK Environment transforms individual MCP servers into a collaborative expert system. All agents listed below are now **ADK-Compliant**, meaning they support the 7-step engineering workflow and integrated security checks.

## 🤖 Unified Agent Directory

### 1. The Orchestrator (The Brain)
- **Agent**: `workflow-orchestrator`
- **Role**: Enforces the 7-step lifecycle across all other agents.
- **Tools**: `init_workflow`, `advance_workflow`, `get_workflow_status`.

### 2. The Guardians (The Shield)
- **Agent**: `check-security` -> Scans for secrets before any ADK action.
- **Agent**: `command-guardrail` -> Validates all shell commands generated by other agents.
- **Agent**: `smart-powershell` -> The only authorized executor for PowerShell scripts.

### 3. The Experts (The Intellect)
- **Agent**: `programming-expert` -> Provides logic and grammar based on official docs.
- **Agent**: `grammar-expert` -> Refines professional communications and CVs.

### 4. The Promoters (The Voice)
- **Agent**: `github-portfolio-manager` -> Manages the public-facing homepage.
- **Agent**: `linkedin-manager` -> Optimizes the professional social presence.
- **Agent**: `create-CV` -> Generates multi-format career documentation (PDF, MD, etc.).

---

## 🛠️ ADK Pipeline Example
To perform a "Smart Sync", the ADK environment executes:
1. `check-security` (Scan workspace)
2. `workflow-orchestrator` (Advance to Documentation step)
3. `create-CV` (Generate latest HEEYUN_CV.md)
4. `command-guardrail` (Validate `git push`)
5. `github-portfolio-manager` (Execute live sync)
