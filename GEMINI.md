# GEMINI: Unified Agentic Framework (UAF) Mandates

## 📡 Ecosystem Overview
This workspace represents a standardized suite of **23+ repositories**, managed by a 28-node Unified Agentic Framework. It serves as the master command center for autonomous software engineering.

## 🏗️ Architectural Mandates
1.  **Hybrid Architecture**: TypeScript for orchestration (Hub) and Go for high-performance systems (FS, Memory). [OPTIMIZED]
2.  **Unified Agent Hub (UAH)**: All Node-based agents consolidated into `unified-agentic-framework` as modular plugins.
3.  **Cognitive Hub**: UAF Hub automatically recalls long-term context from the local **Memory Bank** on every mission.
4.  **Visual Monitoring**: Unified Command Center on Port 8080 with live Memory Stream & DB Stats. [UNIFIED]
5.  **Security Gate**: All `git` and `sync` operations MUST be validated by `security-audit-agent`.
6.  **Configuration Isolation**: Global settings (`~/.gemini/settings.json`) are reserved for cloud services. Local settings (`.gemini/settings.json`) manage project-specific MCP servers.
